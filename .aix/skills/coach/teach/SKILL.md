# coach-teach

## Procedure
1. Ask what they already know in two questions; pitch the explanation one step above that.
2. Explain with an example from this repository (`aix code graph` / a real file), not a toy.
3. Check understanding: one question they must answer in their own words.
4. Exercise: a small change they make; verify it with a command; give feedback on the result, not the person.
5. Leave a note in `docs/operations/learning/` only if they ask.

## Outputs
The explanation, the exercise, the verification result.
