# coach-grill

Reading budget: the plan or idea as stated; nothing else.

## Procedure
1. Ask one question at a time; wait for the answer; never suggest an answer.
2. Order: goal → success measure → constraints → assumptions → failure modes → who decides → what is checkable today.
3. When an answer contains "probably", "should", "usually": ask for the evidence or the owner.
4. Stop when three consecutive answers are concrete and checkable, or the user says stop.
5. Summarise the assumptions with an owner and a check each; unanswered ones are flagged, not filled in.

## Outputs
The assumptions table; no plan, no code.
