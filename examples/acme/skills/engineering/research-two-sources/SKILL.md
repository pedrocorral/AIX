# @acme/research-two-sources

ACME research needs two independent primary sources per claim.
1. Question + the decision it feeds.
2. Two primary sources per claim (spec, official docs for the pinned version, library source); one is a hint, not a finding.
3. Table: claim, sources, version, confidence; contradictions are findings.
4. Note in `docs/operations/research/`; two-line answer on top.
