## 2.21.17 — 2026-09-25

- `aix code graph --functions` builds function-level graphs for JavaScript/TypeScript, Rust and Java by tokens, the same name-based approximation Python gets by AST, so B and the edits work at function level in the four languages. An arc when a call resolves by name: a function of the same file, a name imported by name, `this.m()` / `self.m()` inside a class or impl, `Class.m()` / `Type::m()`, `module.f()` through a module import, `require('./x')()` through `module.exports`. Python gained the same care: calls through a package facade (`flask.url_for()`), `Thing(...)` to `Thing.__init__`. The resolved-calls ratio now counts only calls that could target project code: not builtins and test globals, not library imports, not a parameter, a local or a callback parameter holding a function, not a class without `__init__`, not an inherited `this.method()`. Measured on the extended projects: Flask 92 %, requests 90 %, Excalidraw 70 %, bat 70 %, ripgrep 63 %, commons-lang 97 %, Spring PetClinic 90 %, Express 54 % (41 calls). Below about 70 % the report says B is built on a thin A. `funcgraph.py` (tokens), `pyfuncgraph.py` (Python, split out of `depedges.py`), `tests/test_funcgraph.py`.
- Fixes on the way: Rust's `fn new` was skipped by the style tool (it looked like the JS keyword); generic arrow functions (`<T>(x: T) =>`) were not functions.

## 2.21.11 — 2026-09-25

- `aix code graph` builds two graphs. A is the code: modules and imports in four languages, or Python functions and calls resolved by name, now with the ratio of calls it could resolve. B is the ideal shape of the same nodes under the principle of `architecture/modularity.md`: every node a leaf or a composer, arcs only downward, no cycle, no hub. B is constructed from A (cycles broken at the fewest arcs, Eades, Lin & Smyth 1993; upward arcs cut; levels by longest path from the leaves; hubs split into a leaf part and a composer part) and the distance A -> B is the list of edits with reasons: `CUT a -> b (closes a cycle among 3 nodes)`, `CUT m -> s (upward: layer 1 -> layer 3)`, `SPLIT x (in 5, out 6)`. `--roles` prints every node's level in B and role in A. The gate fails on any CUT; `--max-distance N` caps the edits. What B does not know is printed on every report: unresolved calls, and meaning.
- Gone: "ideal complexity", "reducible %" and SHORTCUT findings. The old ideal was the transitive reduction of A itself, and a direct arc next to a longer path (`a -> c` beside `a -> b -> c`) is a legitimate call, not a defect. The `refactor-shortcut` skill is removed; `--max-reducible` is replaced by `--max-distance`.

The kit itself had 21 leftovers and 2 silent excepts; all fixed. `tests/test_hygiene.py`.
