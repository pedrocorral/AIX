# Persistence abstraction layer

Goal: swapping Postgres for SQLite, Mongo, DynamoDB, files or memory changes **one wiring line** and zero service/model code.

## Ports (interfaces) — live in `backend/app/<domain>/repositories/`
```
Repository[T]              UnitOfWork
  get(id) -> T | None        __enter__ / __exit__ (or async)
  add(entity) -> None        commit() / rollback()
  remove(entity) -> None     <domain>_repo: Repository  (one attribute per repository)
  list(spec, page) -> Page   events: list[DomainEvent]   (collected for outbox)
  find_one(spec) -> T | None
```
- One repository per **aggregate root** (not per table). Child entities are reached through the root.
- Queries are expressed with **specifications** (small objects: `ByEmail(email)`, `ActiveSince(date)`), not with backend query syntax. Complex reporting queries get a dedicated read-model port (`<Domain>ReadModel`) returning DTOs.
- Repositories accept and return **domain models**, never ORM rows/documents.

## Adapters — live in `backend/app/<domain>/adapters/<tech>/`
Mandatory set for every domain: `memory/` (reference implementation, used by unit tests) + the production one.
Optional: `sqlalchemy/`, `mongo/`, `files/`, `http/` (remote service as repository).

## Unit of Work
Services open a UoW, call repositories, commit. Adapters implement commit with the backend's transaction; memory adapter
snapshots/restores. Domain events are collected in the UoW and dispatched **after** successful commit (outbox — see
`../architecture/background-jobs-and-events.md`).

## Rules
1. No SQL/ORM/driver import outside `adapters/` and `migrations/` (lint-enforced).
2. IDs are generated by the domain (UUID v7) so entities are valid before persistence.
3. Every adapter passes the **same contract test suite** (`switching-backends.md`); that suite is the definition of the port.
4. Caching, retries, multi-tenancy filters are **decorators** around repositories, composed in `composition`.
5. Mapping domain ⇄ storage lives in the adapter (`mapper.<ext>`), explicit and boring. Prefer imperative mapping over inheriting ORM base classes in domain models.
6. Pagination returns `Page(items, next_cursor, total?)`; never a raw cursor object.

## Anti-patterns
Repository methods named after SQL (`select_where`); services calling `session.query`; domain models with ORM columns;
"generic repository" exposing the backend's query builder; leaking lazy-loaded proxies past the UoW boundary.
