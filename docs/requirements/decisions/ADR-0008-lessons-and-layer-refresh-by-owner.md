# ADR-0008 — The agents' lessons live in custom/; layers are refreshed by owner
## Context
Agents repeat the same wrong assumptions and unrequested actions; a user corrects them, and the next session has
forgotten. No kit skill can carry these corrections in advance: they are learnt while working. ADR-0002 refreshed
`org/` and `custom/` the same way, by replacing the folder, which would delete anything a project wrote in `custom/`.
## Decision
The method is a kit skill, `core-lessons-learnt` (recognise, propose, write, merge, prune, compact, promote to
`docs/`). The content is the project's skill `core-lessons-learnt-notes` in `.aix/custom/skills/core/`: one file per
lesson, with its author, and a SKILL.md index generated by `aix lessons index`. `aix install` and `aix upgrade` create
it empty when missing and never copy it; the kit checkout holds none. AGENTS.md's session block names it, so every
session reads it. The layer refresh follows the owner: `org/` is the company repository's and is replaced whole
(`--merge-org` merges); `custom/` is the project's and is merged, the source's files replacing the same paths, the
project's own files kept (`--override-custom` replaces it). Every refresh names the lessons when they hold any. The
`.gitignore` rules are unchanged.
## Consequences
A correction given once reaches every later session. One file per lesson keeps parallel additions free of conflicts;
the index is rebuilt after every merge. A merge cannot remove a file the source deleted from `custom/`. While `.aix/`
stays ignored (ADR-0004), the lessons live in one checkout only.
